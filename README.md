# Service Business OS - Netlify Deployment

## Quick Start

### Option 1: Drag & Drop to Netlify (Easiest)

1. Download this entire folder
2. Run `npm install` and `npm run build` locally
3. Drag the `build` folder to Netlify

### Option 2: Connect GitHub Repository

1. Push this folder to GitHub
2. Connect your GitHub repo to Netlify
3. Netlify will auto-build and deploy

## Build Settings (if using GitHub)

- **Build command:** `npm run build`
- **Publish directory:** `build`

## Local Development

1. Install dependencies: `npm install`
2. Start dev server: `npm start`
3. Open http://localhost:3000

## Features

- Google Sheets sync
- Job calendar with drag & drop
- Route planning with Google Maps
- Revenue tracking
- Client management
